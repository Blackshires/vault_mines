# Vault Mines

Frontend-first mock for the Vault Mines casino game concept.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Current mock

- 5x5 grid
- 1 to 20 mines
- bet controls
- mock multiplier / cashout
- gems
- keys (3 per mock round)
- shield
- mine defuse state
- depth HUD
- responsive layout

The mock intentionally keeps game math local and temporary. The frontend contract will later be connected to the RGS without redesigning the interface.
